# 全面优化校园网站

## Goal

对君子大学校园网站进行全面优化，丰富内容、改善 UI 视觉效果、增加交互功能，使网站更加专业、美观、信息丰富。

## Current State Analysis

### 内容问题
- 首页只有 3 条新闻 + 3 条公告，信息密度低
- 新闻/公告列表页只有 10 条数据，偏少
- 学校概况页缺少校园风光图片（只有色块占位）
- 联系方式页地图是纯色块占位

### UI 问题
- Header logo 英文名仍为 "Huawen University"（应为 Junzi University）
- Header logo 图标为"华"字（应为"君"字）
- 首页轮播图是纯色块，没有真实图片感
- 各页面 banner 较单调，缺少装饰元素
- 卡片 hover 效果简单，缺少动画层次
- 新闻卡片图片区域是纯色块占位

### 功能缺失
- 首页缺少"招生信息"和"校园生活"板块
- 新闻/公告列表没有分页或"加载更多"
- 没有回到顶部按钮
- 没有页面过渡动画
- 新闻/公告详情页缺少"上一篇/下一篇"导航
- 没有搜索功能

## Requirements

### UI 优化
1. 修正 Header：logo 图标"华"→"君"，英文名 "Huawen University" → "Junzi University"
2. 首页轮播图增加渐变装饰和更有视觉冲击力的设计
3. 各页面 banner 增加装饰性背景图案（CSS 渐变/几何图形）
4. 卡片 hover 增加微动画（上浮 + 阴影加深）
5. 新闻卡片图片区域改为渐变色块 + 分类图标
6. 全局增加回到顶部按钮（滚动超过一屏后显示）

### 内容丰富
7. 首页新增"招生信息"板块（招生简章摘要 + 快速入口）
8. 首页新增"校园风采"板块（展示校园生活/风光的卡片网格）
9. 新闻数据从 10 条增加到 15 条
10. 公告数据从 10 条增加到 15 条
11. 学校概况页时间线增加更多历史节点（从 5 个增加到 8 个）
12. 联系方式页地图占位区增加装饰性设计

### 功能增强
13. 新闻/公告详情页增加"上一篇/下一篇"导航
14. 页面切换时增加淡入过渡动画
15. 首页数据统计区增加数字滚动动画效果

## Out of Scope

* 后端 API / CMS
* 用户登录/权限
* 搜索功能（需要后端支持）
* 真实图片资源（继续使用 CSS 渐变/色块占位）
* SEO meta 配置
